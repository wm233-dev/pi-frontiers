# Issue 003 AI与数学：看起来正确的证明怎样检查

状态：v0.2已完成[限定语言中的代数恒等式检查演示](guide.md)。本页Lean内容仍为后续扩展，尚未运行Lean验证；首次环境体验超过30分钟仍未成功则暂缓。不能将Python恒等式检查器称为Lean形式化证明。

面向愿意尝试逻辑与简单交互工具的同学，前置为自然数、等式和逐步推理。核心问题：文字解释“像是正确”与给定形式化命题通过检查有什么区别？它连接数学兴趣与计算机辅助验证。

从[Lean官方学习入口](https://lean-lang.org/learn/)进入Natural Number Game的Lean 4教程。拟交付：中文导读、一个简单等式的证明记录、正确与故意错误各一张实际检查截图、练习及答案、环境版本和局限说明。

- [ ] 选择一个入门等式，记录命题与每步依据。
- [ ] 保存真正运行的输入输出，不伪造“验证通过”。
- [ ] 检查没有使用`sorry`或引入未经说明的公理绕过目标。
- [ ] 说明工具检查的是形式化后的命题；翻译原问题的过程仍可能出错。
- [ ] 若用AI提出候选步骤，逐步检查；不能把AI当作证明正确性的来源。

30分钟活动采用5分钟对照、10分钟讲解、10分钟改错、5分钟讨论。这里演示证明检查，不等于训练自动定理证明模型；游戏教程语法也不自动等同于所有标准Lean项目的语法。
