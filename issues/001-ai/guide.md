# Issue 001 从手算进入注意力公式

状态：导读、练习和单查询代码演示已完成；未训练模型，未复现完整论文实验。基础层约25分钟，实践层另15分钟。面向会加权平均的同学，向量可以先理解为一列数。

## 本期到底解决什么

“注意力”经常被说成模型知道该关注哪里。本期不讨论机器是否理解语义，只研究一个可检验计算：给定query、key、value，如何得到权重和输出。输入均为人工设定的小数组，不是训练得到的词向量。

定义query为要匹配的查询向量，key为匹配用的向量，value为被加权汇总的内容向量。key和query维数一致，value维数可以不同；key与value按位置配对，不能随意打乱其中一方。

## 三步算一遍

单查询版本为：scoreᵢ = q·kᵢ / √d，wᵢ = exp(scoreᵢ) / Σ exp(scoreⱼ)，output = Σ wᵢvᵢ。对应原论文第3.2.1节的[缩放点积注意力](https://arxiv.org/html/1706.03762v7)。

设q=[1,0]，k₁=[1,0]，k₂=[0,1]，v₁=[10,0]，v₂=[0,20]，d=2。

1. 点积分别为1和0，除以√2后score约为[0.707107,0]。
2. softmax把分数变成非负且和为1的权重，约为[0.669762,0.330238]。
3. 输出约为[6.697615,6.604769]。输出第二维仍可能较大，因为value的数值尺度不同；权重较大不等于输出的每个分量都更大。

换q=[0,1]时，权重对调，输出约为[3.302385,13.395231]；换q=[0,0]时，两项等权，输出为[5,10]。结果可用[脚本](../../demo/attention.py)独立运行核对。

## 为什么要检查维数和数值稳定性

q和key维数不一致时点积没有这里约定的意义。代码拒绝这种输入，不悄悄截断。计算softmax时先减去最大score，再指数化，数学上权重不变而避免直接对很大的正数取指数。本程序限制小数组和数值范围，不是生产环境的深度学习组件。

## 学生任务与答案

先预测再运行，每题说明理由。

1. q=[0,0]时输出是什么？**答案**：[5,10]，因为分数相同，权重均为0.5。
2. 同时交换k₁/v₁与k₂/v₂的顺序，会改变输出吗？**答案**：不会，配对关系不变，求和次序变化。
3. 只交换value呢？**答案**：通常会，原来的匹配权重现在作用到不同内容上。
4. 把每个score都加10000，权重应改变吗？**答案**：不改变，共同的指数因子在分子分母中抵消。
5. 得到这组输出能否宣称复现Transformer？**答案**：不能，这里只有一个注意力计算，没有学习参数、多头、位置编码、层结构或训练评估。
