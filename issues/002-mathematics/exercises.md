# Issue 002 练习

建议10分钟，可独立完成或两人讨论。先写自己的理由，再打开[答案](answers.md)。

1. **例子与证明（2分钟）**：某程序找到了100万个素数，能否据此证明素数有无穷多个？说明理由。
2. **补全论证（3分钟）**：P是列表中所有素数的乘积，N=P+1。若列表中的p同时整除P和N，那么p也整除____，因此产生矛盾。为什么还要说明“N大于1，所以有素因子”？
3. **寻找错误（3分钟）**：“2×3+1=7、2×3×5+1=31都是素数，所以素数乘积加一总是素数。”用给定数据59×509检查这个结论，并改成证明真正需要的表述。
4. **讨论迁移（2分钟）**：只给出列表3、5，构造得到16。16的素因子是什么？它是否必须大于列表中最大的数？这对“找到列表之外的素数”意味着什么？

自检标准：能够说出“有限例子不等于一般证明”和“N不必是素数”，并解释列表中的素数为什么不能整除N。不会做的题用于定位讲解难点，不据此评价同学能力。
