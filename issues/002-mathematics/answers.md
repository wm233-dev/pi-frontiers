# Issue 002 参考答案

1. 不能。100万个仍是有限多个；可能还有，也可能没有，程序这段输出本身不提供无限结论。需要对任意有限候选列表都适用的论证。
2. 空格填N−P=1。p大于1，不可能整除1。证明N有素因子，是为了确定确实存在某个素数q，再证明q不在已有列表；只说“列表中没有素数能整除N”还没有明确构造出矛盾。
3. 2×3×5×7×11×13=30030；加一为30031=59×509，因此不是素数。正确说法是：有限个素数的乘积加一，大于1，且其任何素因子都不在给出的列表中。
4. 3×5+1=16=2⁴，素因子为2，小于3和5。“不在列表中”不等于“比列表里的数都大”。无穷性论证需要找到列表之外的素数，不需要它比原列表所有元素大。

进阶讨论：如果列表恰好包含所有不超过某个界的素数，那么N的素因子必然超过这个界；这一额外结论依赖“没有遗漏界内素数”的前提。
