# 从阅读到实践的问题卡

下面是一张**示范选题卡，尚未实施**，用于说明如何将兴趣变成可验证任务，不是大创立项材料或已有成果。

| 项目 | 示例 |
|---|---|
| 问题 | 初学者能否理解试除法为什么只需检查到平方根？ |
| 已有知识 | 合数n若两个因子都大于√n，乘积会大于n，因此至少一个因子不超过√n |
| 小实验 | 对2至100的整数比较全范围试除与平方根范围试除，核对判断一致，并记录除法次数 |
| 基线与检查 | 手工核对小样本；用另一种方法如筛法核对全部结果；不只比较运行速度 |
| 所需资源 | Python标准库或纸笔；一位愿意审阅推理的同学 |
| 输出 | 一页算法解释、一张次数对照表、一个可运行脚本、局限说明 |
| 局限 | 小整数实验不能证明对所有整数正确；需单独写出一般论证 |
| 下一步 | 根据实际兴趣继续学习数论或算法；寻求指导后再判断是否适合更完整的实践项目 |

自己填写时回答：问题是什么？依据来自哪里？最小验证怎样做？谁有兴趣？缺哪些知识和资源？先完成一个可解释的小结果，再讨论团队、赛事与申报。
