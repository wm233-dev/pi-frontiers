# 竞聘展示怎样讲清楚这份项目

建议展示约5分钟；正式面试若更短，以通知为准。先介绍部门职责和服务对象，再演示一个关键结果，不逐页朗读执行方案。

| 时间 | 打开什么 | 讲清什么 |
|---|---|---|
| 0:00—0:40 | 工作设想开头 | 先做赛事通知、收表与跟进；用小范围导读支持科创活动 |
| 0:40—1:30 | 六周执行方案 | 谁参加、多久一次、谁准备和复核、怎样控制投入 |
| 1:30—2:40 | Issue 001与注意力脚本 | 输入怎么变、权重和输出怎么变；这里只演示一个公式 |
| 2:40—3:50 | Issue 003最后一个例子 | 七个抽样点都过了仍不等于恒等式成立，说明可靠核查的意义 |
| 3:50—4:30 | 数学基础练习 | 无程序基础的同学也能参与，能完成一道题比听过很多名词更重要 |
| 4:30—5:00 | 状态和评价 | 材料与代码已准备，活动尚未开展；先试讲、获准后试点、依据反馈调整 |

## 三条可执行命令

```sh
python demo/primes.py
python demo/attention.py
python demo/identity_checker.py
```

有时间只展示一个时选注意力；评委追问“如何防止错误传播”时，再展示恒等式检查的适用范围和抽样陷阱。断网不影响脚本；设备故障可用[验证记录](validation.md)，明确展示的是保存结果。

## 展示前必须自己回答的追问

- q、key、value分别是什么，为什么维数必须匹配？
- 为什么改变query会改变权重，却不能直接推断模型效果？
- 30031为什么能反驳“乘积加一必是素数”？
- `counterexample=None`为什么不等于证明成功？
- 为什么恒等式检查器拒绝除法，为什么它不是Lean？
- 如果部门让你先收表、统计材料，活动如何延期和交接？

能够解释再展示。材料和程序采用AI辅助编写，不宣称全部由本人独立从零开发；可准确表述为“围绕自己的工作设想整理了教学材料，并准备核验、试讲和组织试点”。尚未亲自做过的核验或试讲不要使用完成时态。
