# 从“素数有无穷多个”到“素数能靠多近”

这是一张连接[Issue 002数学基础](../issues/002-mathematics/guide.md)与[Issue 003结论核查](../issues/003-ai-mathematics/guide.md)的前沿桥接卡，不新增一期活动。资料核对日期：**2026-09-11**。读者只需了解素数与相邻整数的距离，不需要解析数论基础。

## 1. 从 Issue 002 出发

Issue 002回答“素数是否有无穷多个”，欧几里得式证明给出的答案是有。但它没有告诉我们素数之间能有多近。

素数整体上越来越稀疏，不意味着相邻素数的间距一直增大。例如(3,5)、(5,7)、(11,13)、(17,19)的间距都是2。一个自然的更强问题是：能否找到无穷多对这样近的素数？间距为2的素数对称为孪生素数，“这样的素数对有无穷多”就是孪生素数猜想。列出这些例子还不是证明。

## 2. 三个不同强度的命题

| 命题 | 准确含义 | 当前要区分的状态 |
|---|---|---|
| A | 素数有无穷多个 | Issue 002的证明解决它 |
| B | 存在固定常数H，使无穷多对相邻素数的间距不超过H | bounded prime gaps（有界素数间隔）研究已解决存在性，并不断改进上界 |
| C | 可以取H=2，即无穷多对孪生素数 | 截至核对日期仍未解决 |

设pₙ是第n个素数，可写：

```math
H_1=\liminf_{n\to\infty}(p_{n+1}-p_n).
```

在这里，可以把H₁理解为“会无穷多次出现的相邻素数间距中最小的那个值”；若没有任何有限间距无穷多次出现，则记作无穷大。不必先学会liminf的正式定义。B说明H₁有限，C断言H₁=2。除去最前面的(2,3)，相邻素数都是奇数，间距至少为2。

这些问题逐步加强：C能推出B，B能推出A；仅知道较弱命题，不能倒过来推出较强命题。H₁的定义、bounded gaps的存在性及孪生素数的对应关系可查[Tao的常数条目](https://teorth.github.io/optimizationproblems/constants/88a.html)。

## 3. 2026年的现实前沿案例

长期公开上界为246；Julia Stadlmann的工作给出了240，她的[预印本摘要](https://arxiv.org/abs/2608.31126)明确说明了这一改进。[OpenAI官方页面的脚注9](https://openai.com/index/gpt-6-astra/)则称，GPT-6 Astra帮助建立了更强的186上界：

```math
\liminf_{n\to\infty}(p_{n+1}-p_n)\le 186.
```

也就是**存在无穷多对相邻素数，间距至多为186**。这不要求每对相邻素数都这么近，也不说明其中无穷多对的距离恰好为2。因此，它仍是bounded prime gaps的进展，不能写成GPT-6证明了孪生素数猜想。

246、240、186在此比较的是上界强度，不是一条简单的接力时间线。Tao条目把186材料标为2026-08-30的预印本，把Stadlmann的240标为2026-08-31，并记为同期独立工作；本卡据此不宣称186工作接续了240预印本。官方发布说明也不是独立同行评审，形式化的具体覆盖范围见下文。

186材料中还出现DHL[40,2]：对任意满足admissible条件的40个不同整数偏移组成的集合，存在无穷多个整体平移，使至少两个位置同时取到素数。admissible的意思是：对每个素数模数，这些偏移的余数不会占满所有余数类，从而排除一种显然的整除障碍；这本身不是“必然产生素数”的证明。

把这个结论用于一个最大偏移与最小偏移相差186的特定集合，就能得到上述间距上界。若两个得到的素数之间还夹着其他素数，其中相邻素数的间距只会更小。[PrimeGaps186说明](https://github.com/openai/PrimeGaps186)列出了这一推导目标。本卡不展开筛法，也不把186到2的数值差解释为研究难度只剩多少。

## 4. 看到AI数学突破消息，检查什么

重点是沿用Issue 003的习惯：区分候选结论、证据与工具边界。

| 核查层 | PrimeGaps186案例中的回答 | 不应额外推出什么 |
|---|---|---|
| 1. 官方页面声称什么？ | OpenAI称Astra帮助建立间距上界186，并给出short prime gaps的Proof与supporting research入口 | 不能据官方发布推断独立同行评审已经完成 |
| 2. 数学命题是什么？ | H₁≤186，即无穷多对相邻素数间距至多186 | 不是H₁=2，也不是所有间距都≤186 |
| 3. 证明材料公开了吗？ | 官方页面有证明与配套研究链接；仓库提供Lean 4材料、数值证书及验证说明 | 公开可读不等于本项目已完整审读、复现或确认无误 |
| 4. 形式验证覆盖哪里？ | 仓库报告检查了从显式输入到主要结论的条件证明；另有Python/FLINT数值证书 | 不等于所有输入都已在Lean内证明 |

Tao页面适合定位历史与参考文献，但其贡献说明也披露使用了AI辅助整理、没有独立验证上界或重跑证书。因此，本卡把它作为交叉索引，240回查作者摘要，186及验证范围回查OpenAI仓库，不把该页面当成额外的独立证明审查。

## 5. “形式化了”不等于所有输入都由Lean证明

本次核对的仓库版本为[`61340d0`](https://github.com/openai/PrimeGaps186/tree/61340d0b74163003b32756bb16e91d9209a5e330)。其[形式化元数据](https://github.com/openai/PrimeGaps186/blob/61340d0b74163003b32756bb16e91d9209a5e330/formalization.yaml)记录：Lean 4主要结果包括`PrimeGap186.dhl_40_2`和`PrimeGap186.primeGapLiminf_le_186`，相应目标的`sorry_count`为0。但仍有三个项目特有的显式输入公理：

| 输入名称 | 低门槛理解 | 仍在Lean输入边界之外的部分 |
|---|---|---|
| `kloosterman3_bound` | 一项特定有限域指数和的估计 | 仓库引用已有数学文献作为依据，未在此Lean开发中证明该输入 |
| `kloosterman2_correlation_bound` | 另一项相关和估计 | 同样有文献依据，但在该形式化中仍作为输入 |
| `physical_integral_bounds` | 数值积分与相关上界 | 另有Python/FLINT证书处理数值部分，没有转为该输入的Lean证明 |

这里的“公理”是该开发接受的前提，不等于它们都是未经研究的猜想。前两项据仓库说明来自已有文献；仍需确认引用结果与所用表述、条件相匹配。数值部分有外部工具证据，也仍需检查程序、误差控制和运行环境。

仓库[README](https://github.com/openai/PrimeGaps186/blob/61340d0b74163003b32756bb16e91d9209a5e330/README.md)明确说明：Python证书即使输出成功回执，也不会消除任何Lean输入公理；报告的环境还涉及未随仓库捆绑的定制FLINT构建。本项目没有重跑该证书或Lean构建。

因此，准确说法是：**PrimeGaps186提供带明确验证边界的条件式Lean形式化：机器检查了接受这些输入后到结论的推导，没有独立证明全部输入。**比较器还允许`propext`、`Quot.sound`、`Classical.choice`等逻辑基础公理，不能把“有三个项目输入”误写为“总共只有三个公理”。

“目标不使用sorry”也不等于“整个仓库没有任何占位”。元数据只给出主要结果的零`sorry`记录；README说明`Challenge.lean`另有用于陈述检查目标的占位。其审阅状态为self-assessed，未有独立人工语义审阅。本卡转述的是已公开的验证范围，不声称自行完成了证明审计，也不因此否定这些条件证明的价值。

## 6. 给学生的5分钟问题

1. 已知“无穷多对相邻素数的间距≤186”，为什么不能推出“无穷多对的间距=2”？
2. 若Lean定理依赖若干显式输入公理，机器检查了什么？哪些部分仍需人工、文献或其他工具确认？

讨论提示：第一题关注“上界”与“指定值”的区别；第二题区分“从前提到结论的推导”和“前提本身的依据”。无需做复杂计算，也不要求读者验证研究论文。
