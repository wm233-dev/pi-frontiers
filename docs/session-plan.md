# 一次30分钟的试点如何开展

对象：拟邀请3—5名自愿参加的低年级同学。状态：主持流程样稿，未举行。

开展前先确认部门同意、时间地点和内容审阅。准备本地导读与练习即可，没有投影时用纸或个人设备阅读；不要求付费软件。主持人和资料复核人可由两人分担，具体人员待邀请，不能先写老师已支持。

| 时间 | 主持动作 | 同学产物 |
|---|---|---|
| 0—5分钟 | 展示2、3、5等例子，问“列举够多能证明无限吗” | 写一句直觉 |
| 5—15分钟 | 按导读解释构造与素因子；突出30031反例 | 圈出自己不理解的一步 |
| 15—25分钟 | 发四道练习，先独立想再讨论；有余量运行程序 | 练习答案与理由 |
| 25—30分钟 | 用参考答案纠错，收两条简短反馈 | 最难处、下一步兴趣 |

两分钟展示路线：说明服务对象与本职优先（20秒）→打开导读并指出关键错误（40秒）→展示练习与程序输出（40秒）→说明试点与未完成事项（20秒）。程序打不开时直接看验算表，不能声称正在现场运行。

活动前检查：

- [ ] 自己不用照稿也能讲清“有素因子”的理由。
- [ ] 关键内容已获适当审阅；未审核不称正式教学成果。
- [ ] 练习和答案分别保存，离线可打开。
- [ ] 与课程和部门事务不冲突，无需额外购买软件。

活动后按[反馈模板](feedback.md)记录实际情况。若无人参加，先做自测并调整招募方式；没有参与者就没有“用户反馈”。两次试点后评估是否继续，时间超预算、需求不足或可靠性无法保障时暂停。
