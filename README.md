# π Frontiers · 学术前沿阅读计划

这是为创新实践部竞聘准备的个人项目样稿。**当前已形成工作设想和一期完整教学Demo；尚未开展实际活动，也未获得部门批准或教师审阅。**材料与代码使用AI辅助起草，需由展示者阅读、理解并试讲后使用。经典证明是入门基础，不是原创研究或最新科研成果。

## 最小活动形式

面向有兴趣的低年级同学，拟从3—5人、一次30分钟的体验开始：5分钟提出问题，10分钟导读，10分钟练习，5分钟讨论。先服务部门现有讲座和特色活动，再根据反馈决定是否尝试两周一期；考试周暂停。

不要求编程或整篇英文论文阅读能力。每期只解决一个问题，保留一页导读、一道可完成的练习和可追溯的来源。后续有兴趣的同学可以继续形成问题卡、小实验，再按实际条件寻求大创、建模等实践机会。

## 运行验算

只需Python 3.10或以上，无第三方包、网络或API密钥。在仓库目录执行：

```sh
python demo/primes.py
python -m unittest discover -s tests -v
```

程序展示三组有限素数列表，验证“乘积加一”的素因子不在原列表中。它只是检查例子；素数无穷多的一般性结论由[文字证明](issues/002-mathematics/guide.md)给出。
