从一个能理解的问题开始，用导读、讨论和小实践，逐步走向数学与人工智能的学术前沿。

这是为创新实践部竞聘准备的个人项目样稿。**v0.2已形成详细工作设想、六周执行方案和三个可运行教学演示；尚未开展实际活动，也未获得部门批准或教师审阅。**材料与代码使用AI辅助起草，需由展示者阅读、理解并试讲后使用。经典证明是入门基础，不是原创研究或最新科研成果。

## 最小活动形式

面向有兴趣的低年级同学，拟从3—5人、一次30分钟的体验开始：5分钟提出问题，10分钟导读，10分钟练习，5分钟讨论。AI和交叉主题可加10分钟进阶实践，总计40分钟。先服务部门现有讲座和特色活动，再根据反馈决定是否尝试两周一期；考试周暂停。

不要求编程或整篇英文论文阅读能力。每期只解决一个问题，保留一页导读、一道可完成的练习和可追溯的来源。后续有兴趣的同学可以继续形成问题卡、小实验，再按实际条件寻求大创、建模等实践机会。

## 运行验算

只需Python 3.10或以上，无第三方包、网络或API密钥。在仓库目录执行：

```sh
python demo/primes.py
python demo/attention.py
python demo/identity_checker.py
python -m unittest discover -s tests -v
```

三个脚本分别演示素数构造例子、注意力公式和受限多项式恒等式检查。全部12项测试通过，具体范围见[验证记录](docs/validation.md)。素数程序只检查例子；一般性结论由[文字证明](issues/002-mathematics/guide.md)给出。恒等式程序不是Lean，不调用大模型，不接受任意自然语言证明；Lean仍为[后续学习计划](issues/003-ai-mathematics/plan.md)。

## 基础如何走向前沿

| 本期训练 | 下一步问题 | 尚缺的知识或证据 |
|---|---|---|
| 注意力公式的小数组计算 | 观察查询尺度变化对权重的影响，回看论文解释 | 多头、训练、数据与评测，不可用小算例替代 |
| 例子与一般证明的区别 | 阅读一个定理时识别假设、引理和推理缺口 | 更完整的专业课程与证明训练 |
| 候选结论与核查分离 | 尝试Lean 4入门，理解形式化命题和检查边界 | 真正运行的Lean证明与审阅，尚未完成 |

项目名称中的“前沿”是逐步进入的方向；当前样稿先建立阅读和验证方法，不把经典内容包装成最新成果。

一个现实入口是[素数无穷多个 → bounded prime gaps → twin prime conjecture](docs/frontier-bridge-prime-gaps.md)：2026-09前沿案例为GPT-6 Astra参与的H₁≤186结果，**不是孪生素数证明**。桥接卡同时说明PrimeGaps186的条件形式化与验证边界，不增加新一期活动。
